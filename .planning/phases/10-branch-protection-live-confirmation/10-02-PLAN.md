  <name>Task 1: Open scratch PR without changeset — confirm gate bites</name>
  <read_first>

  <action>
Execute the following commands from the repo root. Note: Plan 01 must have run first (branch protection must be live before merge-block is observable).

Step 1 — Create a scratch branch from develop:
```
git fetch origin develop
git checkout -b test/gate-verification origin/develop
```

Step 2 — Make a trivial README-only change (no .changeset/ file):
```
echo "" >> README.md
git add README.md
git commit -m "chore: scratch commit for gate verification (no changeset)"
git push -u origin test/gate-verification
```

Step 3 — Open a PR against develop:
```
gh pr create \
  --base develop \
  --head test/gate-verification \
  --title "chore: gate verification scratch PR (will be closed)" \
  --body "Scratch PR to prove changeset-check gate. No changeset intentionally. Will be closed after verification." \
  --draft
```
Note the PR number from the output (e.g. "https://github.com/appifex-ai-org/appifex-dtc/pull/N").

Step 4 — Wait for changeset-check to run and fail (typically 30-60 seconds), then check status:
```
gh pr checks <PR-number> --watch
```
Expected: changeset-check shows "fail" with annotation "No changeset entry found in this PR."

Step 5 — Confirm merge is blocked:
```
gh pr view <PR-number> --json mergeStateStatus,statusCheckRollup
```
Expected: `"mergeStateStatus": "BLOCKED"` and changeset-check entry with state="FAILURE".

Capture the PR URL and the full output of `gh pr checks <PR-number>` at this point.
  </action>
  <verify>
    All of the following must be confirmed from the gh pr output:

    1. changeset-check job status is FAILURE (not pending, not success)
    2. The job logs contain the line: `No changeset entry found in this PR.`
    3. mergeStateStatus is "BLOCKED" (not "CLEAN" or "UNSTABLE")

    Verification command:
    ```
    gh pr checks <PR-number> --json name,state,conclusion \
      | jq '.[] | select(.name == "changeset-check")'
    ```
    Expected output contains `"conclusion": "FAILURE"` or `"state": "FAILURE"`.
  </verify>
  <done>
    - Scratch PR opened against develop with README-only change
    - changeset-check job ran and failed with ::error:: annotation
    - mergeStateStatus=BLOCKED confirmed
    - PR number and job URL captured for documentation
  </done>

Continue from Task 1's scratch branch. The same PR (same PR number) is used.

Step 1 — Add an empty changeset:
```
pnpm exec changeset --empty
```
This creates a file like `.changeset/shiny-foxes-eat.md` with a minimal frontmatter. Verify it was created:
```
ls .changeset/*.md | grep -v README | grep -v config
```
Expected: one new .md file (e.g. `.changeset/shiny-foxes-eat.md`).

Step 2 — Commit and push:
```
git add .changeset/
git commit -m "chore: add empty changeset for gate verification"
git push
```

Step 3 — Watch both checks complete:
```
gh pr checks <PR-number> --watch
```
Expected outcome within ~5 minutes:
- changeset-check: pass (green)
- e2e-build: pass (green, should show "Build phase reached" or similar in logs)

Step 4 — Confirm e2e-build ran without LLM calls (check the job logs for DTC_LLM_MODE):
```
gh run list --workflow=e2e.yml --limit 5 --json databaseId,status,conclusion,displayTitle \
  | jq '.[] | select(.displayTitle | contains("gate verification"))'
```
Note the run ID from the output.

```
gh run view <run-id> --log | grep -E 'DTC_LLM_MODE|fixture|xcodebuild|xcodegen|ANTHROPIC' | head -20
```
Expected: lines showing `DTC_LLM_MODE=fixture` or "fixture" mode active; NO line containing `ANTHROPIC_API_KEY` with a real key value.

Step 5 — Confirm merge unblocked (only code-owner review should remain):
```
gh pr view <PR-number> --json mergeStateStatus,statusCheckRollup
```
Expected: mergeStateStatus is no longer "BLOCKED" due to status checks (it may show "BLOCKED" only because code-owner review is still required — that is the correct state).

Step 6 — Close and delete the scratch PR and branch (do NOT merge):
```
gh pr close <PR-number> --delete-branch
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scratch PR → CI runners | GitHub Actions runner executes e2e-build; fixture mode ensures no LLM token spend |
| changeset-check job → merge gate | job conclusion drives mergeStateStatus; tested by this plan |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-04 | Tampering | scratch PR accidentally merged | mitigate | PR is opened as --draft; close --delete-branch in Step 6 of Task 2 without merging |
| T-10-05 | Information Disclosure | e2e-build logs expose secrets | accept | e2e.yml confirmed to have no ANTHROPIC_API_KEY; DTC_LLM_MODE=fixture suppresses all outbound LLM calls |
</threat_model>
