<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local shell → GitHub API | gh CLI sends PUT to branch protection endpoint; requires repo-admin token |
| branch protection → CI | GitHub enforces required_status_checks on PR merge; prevents bypass without admin override |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Elevation of Privilege | Branch protection enforce_admins=false | accept | Solo-founder escape hatch per D-09; repo admin can still merge in emergencies; documented in script header |
| T-10-02 | Tampering | CODEOWNERS file modification | mitigate | CODEOWNERS itself is protected (/.github/ @rayliu-factory in CODEOWNERS); branch protection requires code-owner review to merge changes to CODEOWNERS |
| T-10-03 | Spoofing | gh CLI auth token compromise | accept | Token lives in ~/.config/gh/hosts.yml on dev machine; not committed; risk accepted for solo-founder workflow |
</threat_model>
