<objective>
Fix the token estimator to reflect real Swift token density (CHARS_PER_TOKEN 4 → 3) and add a hard guard so the fix loop never starts with less than 30% of the total budget remaining. This closes FOUND-02.

Purpose: Prevent silent prompt truncation (estimator-under-count) and prevent fix-loop attempts that cannot converge because the budget is already spent.

Output: Two constant edits in `@appifex/analysis`; `FIX_LOOP_MIN_RESERVE_RATIO = 0.30` + `canEnterFixLoop()` method + public `get total()` getter on `TokenBudget`; fix-loop guard throwing `BudgetExhaustedError`; three test files (two extended, one new).

Non-breaking API change: add an optional sibling field `budgetInstance?: TokenBudget` to `FixLoopOpts` so the guard can read real `TokenBudget` state without changing the existing `tokenBudget: number` field.
</objective>
