## Overview

Brownfield hardening milestone. The pipeline architecture, design adapters, SwiftUI/Kotlin codegen, Firebase templates, LLM fix loop, and MCP server already existed. This milestone first made the repo open-source-ready (Phase 1), then integrated and hardened the SwiftUI + Firebase path end-to-end so a solo founder can run one command and get a TestFlight build from a design file — no manual Xcode or Firebase console steps. Phases flowed in strict dependency order: open-source release readiness first, then fix the broken foundation, credential-gate third, wire Firebase fourth (its plist is a build input), archive and upload fifth, harden the validation loop sixth, finish adapter parity and surface polish seventh, then formal verification and live confirmation.

## Milestone Summary

**Key Decisions:**

- Narrowed v1 to SwiftUI + Firebase only (depth before breadth)
- js-yaml over regex for project.yml mutation — type-safe parse/mutate/serialize
- Changesets in-repo enforcement (no GitHub App) — zero third-party dependencies
- Anthropic structured outputs for fix response schema — no custom delimiter parser
- archiver v7 for debug-bundle zip (pure JS, no native deps; zlib level 6)
- sanitizeLayerName wired into spec extractors (not adapter files) for Pencil/MCP path
- emit() extended with optional 5th arg costFields bag — preserves all existing call sites
- Opus 4.x pricing confirmed at $5/$25 per MTok — PRICING_AS_OF stamp added

**Issues Resolved:**

- Broken absolute symlink for `bin/dtc` (FOUND-01) — replaced with portable shim
- EPIPE silent truncation at 4 LLM stdin sites (FOUND-03)
- MCP `process.exit` killing host (FOUND-04) — isolated via `wrapToolHandler`
- Swift token density overestimated (4→3 chars/token, FOUND-02)
- `pnpm install` ELIFECYCLE when `core.hooksPath` set locally (Phase 2 gap, 02-05)
- Unconditional semgrep was gated behind `baseTestsPassed` — removed guard

**Issues Deferred:**

- Agent-orchestrated path exits at pipeline.ts:3307 before TestFlight phases (WR-05 / INT-01)
- `archiveSwift(success=false)` not guarded — silent checkpoint on xcodebuild failure (WR-01 / INT-02)
- `e2e_gate` not in `FORCE_RERUN_PHASES` — stale checkpoint on resume (WR-02)
- Live TestFlight delivery not confirmed (TF-01..04 human verification pending)

**Technical Debt Incurred:**

- `testflight-polling.ts` phaseId defaults to 'provision' not 'testflight_upload' (WR-02)
- `D-16` idempotent skip discards buildId → tester reconciliation fails on resume (WR-03 / INT-03)
- `parseInt(version,10)` silently truncates non-integer build versions (WR-04)
- `securityLintPassed = config.baas?.provider !== 'firebase' || true` always true — security-lint variable semantically dead (WR-05 Phase 6)
- Maestro error id regex rejects quoted ids and can false-positive on Swift type annotations (WR-03/WR-04 Phase 6)
