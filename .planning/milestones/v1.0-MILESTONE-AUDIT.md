### Critical Integration Gap: Agent Path Bypasses TestFlight

`detectAgent()` in the CLI finds any agent CLI on PATH (`claude-code`, `codex`, `gemini`). When found, the pipeline takes the agent-orchestrated branch (lines 2853–3307) and returns **before** e2e_gate, xcode_archive, and testflight_upload. This means any user with Claude Code CLI installed gets codegen + security scan but **no TestFlight upload**.

The core value promise ("Design to TestFlight in one command") is silently broken on the agent path. The MCP `dtc_testflight_upload` tool is not affected — it invokes the phases directly.

Affected REQ-IDs: TF-01, TF-03, TF-04, VAL-01
