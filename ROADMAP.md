# Roadmap

## v1.0 — Design to TestFlight (released)

- SwiftUI + Firebase end-to-end pipeline
- Pencil, Figma, and Stitch design adapters
- Maestro UI test generation and validation gate
- Semgrep security scan gate
- LLM-assisted auto-fix loop with token budget
- Checkpoint / resume for interrupted runs
- MCP server for agent-driven workflows
- Multi-provider LLM support (Claude, Copilot, OpenAI, Gemini)

## v1.x — Hardening and breadth (in progress)

- Kotlin Compose + Firebase target (Android)
- Formal verification layer for generated code contracts
- Expanded design parity checks (delta detection between design updates and generated code)
- Observability: structured run logs and failure audit trail
- E2B remote sandbox execution

## v2.0 — Multi-platform (planned)

- React (web) target
- React Native target
- Supabase BaaS support as a first-class alternative to Firebase
- Google Play delivery path
- Design system round-trip: generated code changes reflected back to design file
